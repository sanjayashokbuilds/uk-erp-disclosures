# What UK-listed companies are telling shareholders about SAP

SAP stops mainstream maintenance for ECC 6.0 at the end of 2027. I read the latest annual report of every UK-listed company (538 readable reports) to find which ones are telling shareholders they're mid-migration, struggling, or running a system that's about to lose support. Each company name below links to its annual report, and each quote can be found with Ctrl+F.

## How it works

1. **Reports** (`erpmap/fetch.py`): UK main-market companies have to file their annual report digitally (ESEF / Inline XBRL), and filings.xbrl.org collects these. The script lists every GB filing since mid-2024, keeps the latest one per company, skips investment trusts and funds, downloads each report and extracts the text page by page. Companies House isn't used because large companies' accounts there are stored as scanned images with no text.
2. **Scan** (`erpmap/scan.py`): the scan is rules-based, so every result traces back to a quote. It finds mentions of SAP, S/4HANA, SAP ECC, ERP, Oracle ERP and Dynamics 365, then looks within a few hundred characters for delays, overruns, write-offs, exceptional costs, disruption and end-of-support language. It drops non-software meanings of "SAP" (energy ratings, share award plans) and director bios.

## Limitations

- It only sees what companies choose to disclose. A silent report doesn't mean there's no programme.
- It covers main-market companies on filings.xbrl.org, not AIM companies or private groups.
- It uses each company's latest report only. Reports filed as images (66 of 604) are skipped.

## Run it

```
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m erpmap.fetch --limit 10   # test
python -m erpmap.fetch              # everything (about an hour)
python -m erpmap.scan
```

Data: annual reports via filings.xbrl.org (XBRL International).
